# OOPS Banner App

A Java application demonstrating Object-Oriented Programming System (OOPS) concepts through an interactive banner display application.

## Project Overview

This project is designed to progressively implement various OOPS concepts and features through different use cases (UCs). Each use case builds upon the previous one, adding new functionality and demonstrating key object-oriented principles.

## Current Status

**Latest Completed UC:** UC1

### UC1 - OOPS Banner Display
- Simple Java application that displays the "OOPS" acronym to the console
- Entry point for understanding basic Java program structure
- Demonstrates the fundamentals of the application framework

```
└── README.md            # This file
```

## Development Workflow

- **main**: Stable, production-ready code
- **dev**: Integration branch for completed features
- **feature/uc#**: Individual branches for each use case development

Each use case is developed in its own feature branch (`feature/uc1`, `feature/uc2`, etc.) and merged to `dev` upon completion, then integrated to `main` for release.

## Getting Started

- Git
